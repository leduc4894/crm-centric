## Generator selection and prerequisites

The two canonical OpenAPI 3.1 documents generate TypeScript types using openapi-typescript 7.13.0, with openapi-fetch 0.17.0 as transport, and C# clients using Corvus.Json.Cli 5.8.8. The CLI NuGet artifact SHA-256 is `b023226e7cffe4b58578ed51c460424cfadfbfe4b223abae020b6e5960a68051`; .NET build/runtime dependencies have NuGet locks. The pinned .NET SDK image digest and all selected versions are in `tools/contracts/toolchain.json`; Node/npm are pinned in `.node-version` and `package.json`. Generated code is local only; it is not evidence of implemented business routes or server validation.

The initial OpenAPI Generator 7.27.0 TypeScript Fetch and Generic Host C# candidates produced code that lost valid action fields. Its RestSharp C# template could round-trip individual actions but rejected valid recursive conditions and exposed payloads in diagnostics. NSwag 14.7.1 failed to compile the actual CRM contract; Kiota 1.38.0 generated an action union whose factory did not populate its member. Those experiments did not establish that other versions or configurations cannot work.

Install the exact Node/npm versions, Docker, and Python contract dependencies. Populate npm's cache using `npm ci --ignore-scripts`, then place the official `corvus.json.cli.5.8.8.nupkg` under `.local/plan3-tools/`; `generate.py` verifies its SHA-256 before extraction and executes the generator in a network-isolated pinned container. Retrieve the artifact from the NuGet flat-container endpoint `https://api.nuget.org/v3-flatcontainer/corvus.json.cli/5.8.8/corvus.json.cli.5.8.8.nupkg`. The package is not committed. Generation installs locked npm dependencies into an isolated temporary directory with `npm ci --offline --ignore-scripts` and does not execute npm lifecycle scripts. `check.py` regenerates in a temporary directory and compares full generated trees without writing generated content into the workspace.

The Corvus lock file's `generatedAt` field is removed and generated C# line endings are normalized to LF before comparison; all other generated bytes are retained. Provenance in each output records per-file hashes for the validated transitive local input closure, plus generator artifact and configuration hashes. These are local checks, not a claim about published packages or remote CI.
